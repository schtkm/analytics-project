## Akcja doskonaląca

**Cel:** Usprawnienie współpracy zespołowej z wykorzystaniem systemu Git.

**Zakres działań:**
- Samodzielne przejście przez tutorial dotyczący obsługi Git 
  przez każdego członka zespołu.
- Zapoznanie się z podstawowymi operacjami: clone, pull, commit, 
  push oraz obsługą gałęzi.
- Wykorzystywanie integracji Git w środowisku Visual Studio 
  podczas realizacji zadań projektowych.

**Odpowiedzialność:** Wszyscy członkowie zespołu.

**Termin realizacji:** Do końca Sprintu 2.

**Kryterium sukcesu:** Każdy członek zespołu potrafi samodzielnie 
wykonywać podstawowe operacje Git i wykorzystuje je podczas 
realizacji zadań projektowych.

**Weryfikacja:** Podczas Sprint 2 Retrospective.
